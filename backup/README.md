# Thư mục backup

File backup database **không nằm trong thư mục này** vì dung lượng vượt giới hạn upload của GitHub (25 MB mỗi file khi upload qua giao diện web).

File backup được đính kèm trong mục **Releases** của repo:

👉 https://github.com/Phase1-team/DangLH-Levis/releases

## Thông tin bản backup

| Mục | Giá trị |
|---|---|
| Database | `lehaidang-db` |
| Phiên bản | Odoo 19 |
| Định dạng | zip (gồm database và filestore) |
| Release | `backup-2026-10-09` |
| File | `lehaidang-db_2026-10-09.zip` |

## Cách tải

1. Mở trang Releases ở link trên.
2. Chọn bản `Backup lehaidang-db 2026-10-09`.
3. Ở phần **Assets**, tải file `lehaidang-db_2026-10-09.zip`.

Repo ở chế độ private nên cần đăng nhập tài khoản GitHub có quyền truy cập mới tải được.
